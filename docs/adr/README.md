# سجل القرارات المعمارية (ADR)

كل قرار كبير يُكتب في ورقة مستقلة: السياق، والخيارات التي درسناها، والقرار، والسبب، والعواقب. **لا نحذف قرارًا قديمًا.** إذا تغيّر القرار، نكتب ورقة جديدة تحل محله، ونغيّر حالة القديمة إلى «استُبدل بـ ADR-xxxx».

**الحالات الممكنة**:
- **مقترح**: ينتظر موافقة المالك.
- **مقبول**: وافق عليه المالك.
- **استُبدل**: حلّ محله قرار أحدث.
- **مرفوض**: لن نعمل به.
