# الاختبارات اليدوية

> **English summary.** A short manual checklist for what automated tests cannot prove on a real Windows machine: installer, WebView2, file locks and antivirus, removable drives, the browser extension, notifications, and uninstall. Anything not run is marked «لم يُختبر».

الاختبارات الآلية تغطي المحرّك والواجهة. أما ما يلي فيحتاج جهازًا حقيقيًا.

## 1. قبل الإصدار

- [ ] ويندوز 10 (17763 أو أحدث) وويندوز 11، على x64.
- [ ] ويندوز نظيف بلا WebView2 مثبّت مسبقًا.
- [ ] حساب مستخدم عادي، بلا صلاحيات مدير.
- [ ] قرص NTFS، وقرص exFAT (USB)، وقرص FAT32.

## 2. المثبّت

- [ ] التثبيت يعمل بلا طلب صلاحيات مدير.
- [ ] يفهم لغتي المثبّت (العربية والإنجليزية).
- [ ] تظهر أيقونة مَرْسَى الصحيحة في قائمة ابدأ وفي «التطبيقات».
- [ ] التشغيل الأول يفتح النافذة، والواجهة عربية RTL.
- [ ] إلغاء التثبيت يزيل البرنامج، ويترك ملفات المستخدم كما هي، ولا يترك خدمة أو مهمة مجدولة.

## 3. التحميل

- [ ] ملف 100 ميجابايت يكتمل بسرعة معقولة.
- [ ] ملف 4 غيغابايت يكتمل، والحجم النهائي مطابق.
- [ ] القطع في منتصف التحميل ثم الاستكمال من نفس النافذة.
- [ ] إغلاق البرنامج أثناء التحميل، ثم فتحه: يعود التحميل من حيث توقف.
- [ ] «أوقف وانتظر» يعيد التحميل إلى الانتظار فورًا، والاستئناف يكمل.
- [ ] ملف على سيرفر لا يدعم التقسيم: اتصال واحد، ويكتمل.
- [ ] ملف تغيّر على السيرفر: يبدأ من جديد ويقول ذلك، ولا يخلط نسختين.
- [ ] اسم مستخدم موجود: يصبح `الاسم (1).امتداد`، ولا يُكتب فوق الملف.
- [ ] ملف على exFAT: يكتمل، والاسم الصحيح يبقى.
- [ ] قرص ممتلئ: رسالة واضحة، ولا ملف يتيم.
- [ ] ملف بحجم 0، وملف بلا `Content-Length`: سلوك واضح بلا تعطّل.

## 4. الملفات والقفل

- [ ] أثناء التحميل، يفتح برنامج آخر الملف الجزئي: لا يفسد التحميل.
- [ ] حذف الملف الجزئي من مستكشف الملفات أثناء التحميل: رسالة واضحة، لا تعطّل.
- [ ] برنامج حماية يفحص المجلد أثناء التحميل: لا يفشل الحذف أو إعادة التسمية (إعادة المحاولة تعمل).
- [ ] ملف حالة من جهاز آخر: يُرفض إن كان فاسدًا، ولا يُلمس الملف الجزئي.
- [ ] ملف `.tar.gz` مكتمل: زر «استخراج» في «التفاصيل» يظهر، ويستخرج إلى `<الاسم>_extracted/`. وملف `.rar` أو `.7z`: الزر لا يظهر.
- [ ] أرشيف فيه مدخل `../evil.txt`: يظهر خطأ واضح، ولا يُنشأ أي ملف خارج مجلد الاستخراج.

## 5. الروابط والمتصفح

- [ ] إضافة Chrome/Edge: التقط رابط تحميل، ووصل إلى مَرْسَى.
- [ ] إضافة Firefox: نفس الشيء.
- [ ] الإضافة لا تعمل إن لم يكن `marsa-host` مثبتًا، وتقول ذلك.
- [ ] رابط فيه `user:pass@`: لا تظهر بيانات الدخول في الواجهة ولا في ملف الحالة.
- [ ] رابط فيه `?sig=…`: يبقى في ملف الحالة للاستكمال، ولا يظهر في أي رسالة أو سجل.
- [ ] كوكيز المتصفح: تُرسل للرابط نفسه فقط، ولا تُحفظ على القرص.

## 6. القوائم والجدولة

- [ ] ثلاث قوائم، كل واحدة بحد تحميلات مختلف.
- [ ] نافذة زمنية تبدأ وتنتهي في الوقت المحلي الصحيح.
- [ ] «ابدأ الآن» يشغّل قائمة خارج نافذتها.
- [ ] حد السرعة العام وحد التحميل الواحد: السرعة الفعلية قريبة من الحد.
- [ ] إيقاف البرنامج أثناء تشغيل الطابور: التحميلات تعود إلى الانتظار عند الفتح.

## 7. الفئات

- [ ] فئة بموقع، وفئة بامتداد، وفئة بلا مجلد: لا ينشأ مجلد لم يطلبه المستخدم.
- [ ] «جرّب اسمًا» يعرض الفئة الصحيحة.
- [ ] ملف مكتمل يحمل علامة «من الإنترنت» (خصائص → General → Unblock).

## 8. الفيديو والأدوات

- [ ] أول طلب فيديو يعرض الأدوات وترخيصها ويطلب الموافقة.
- [ ] رفض التنزيل يمنع تحميل الأدوات.
- [ ] بعد التنزيل، يوتيوب يعمل، وبصمة SHA-256 تُتحقق قبل كل تشغيل.
- [ ] أداة ناقصة أو تالفة: رسالة واضحة، ولا تشغيل.

## 9. الواجهة والوصول

- [ ] لوحة المفاتيح: Tab وShift+Tab وEnter وEscape في كل نافذة.
- [ ] قارئ الشاشة (NVDA) يقرأ أسماء التحميلات وحالاتها.
- [ ] التباين العالي في ويندوز لا يخفي نصًا.
- [ ] تكبير الواجهة 200% لا يقطع الأزرار.
- [ ] الوضع الداكن والفاتح، والعربية والإنجليزية، بلا نص مقطوع.

## 10. ماك ولينكس

**لم يُختبر في هذه النسخة.** يُنفَّذ هذا الملف كاملًا على كل نظام قبل أول إصدار له، مع:
- [ ] Gatekeeper وnotarization على ماك.
- [ ] AppImage و`.deb` على لينكس.
- [ ] إلغاء التثبيت النظيف على النظامين.

## 11. التحديث الموقّع (ADR-0011)

**لم يُختبر بعد**: لا إصدار منشور ولا إصدار `updater`، فالعنوان الذي يسأل عنه مَرْسَى يرد 404 اليوم. ما يثبته الاختبار الآلي الآن: قبول تحديث صحيح، ورفض توقيع غريب أو لنسخة أخرى أو ملف تغيّر بعد توقيعه، ورفض شهادة TLS غير موثوقة أو موقّعة ذاتيًا (`crates/marsa-core/tests/update_manifest.rs`).

على جهاز حقيقي، بعد نشر إصدارين موقّعين:

- [ ] نسخة `0.1.0` مثبّتة، ثم `0.1.1` منشورة: يظهر إشعار النسخة الجديدة.
- [ ] «حدّث الآن»: يُنزَّل الملف، ثم يُثبَّت، ثم يُفتح مَرْسَى `0.1.1`.
- [ ] «لاحقًا»: لا تنزيل، ويبقى الإشعار.
- [ ] «تخطَّ هذه النسخة»: لا يظهر الإشعار ثانية عند إعادة الفتح، ويظهر إشعار `0.1.2`.
- [ ] تحميل جارٍ عند «حدّث الآن»: يُوقف بعد حفظ تقدمه، ويُستكمل بعد التحديث.
- [ ] `latest.json` موقّع بمفتاح آخر: لا يُعرض «حدّث الآن» (رابط صفحة الإصدار فقط).
- [ ] `latest.json` بنسخة أقدم أو مساوية: لا إشعار.
- [ ] قطع الشبكة أثناء تنزيل التحديث: رسالة، ولا تثبيت.
- [ ] برنامج حماية يمسك `marsa-desktop.exe` أثناء التحديث: المثبّت يعيد المحاولة عشر ثوانٍ، ثم يقول خطأ واضحًا.
- [ ] SmartScreen بعد التحديث: ما يظهر، وهل يختلف عن التثبيت الأول.
